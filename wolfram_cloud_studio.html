Documentation

What is Wolfram Cloud Studio?

A self-contained browser UI for Wolfram Language computation and Wolfram|Alpha queries. It works standalone (offline/demo) or connected to a live WL backend deployed on Wolfram Cloud.

Getting started

  • Open this file in any browser — the UI is fully functional immediately
  • For live WL evaluation, deploy wolfram_cloud_studio.wl and paste the URL in Overview → Backend Connection
  • Theme toggle is in the top-right corner; preference is saved locally
  • All history is saved in sessionStorage and can be replayed

Wolfram Language Evaluator

Evaluates WL expressions via the connected backend. In demo mode, returns a mock response.

Example expressions

  • Prime[1000]
  • Table[i^2, {i, 10}]
  • Solve[x^2 - 5x + 6 == 0, x]
  • FactorInteger[2^64 - 1]
  • StringJoin[Riffle[{"a","b","c"}, "-"]]

Keyboard shortcut

Ctrl+Enter / Cmd+Enter runs the current panel.

Wolfram|Alpha Integration

Sends natural-language queries to WolframAlpha via the backend. Works best for factual and scientific questions.

Good queries

  • distance from Earth to Mars
  • population of Tokyo 2024
  • integral of sin(x)^2
  • 100 USD in EUR
  • speed of light in furlongs per fortnight

Context Detection

Runs ps -ax on the backend host and classifies processes by dev tool type (Vite, FastAPI, Node, Jupyter, etc.).

Detected process kinds

  • ViteFrontend · NextWebApp · WebpackFrontend
  • FastAPIService · FlaskService · DjangoService · JupyterService
  • NodeService · PythonService · WolframService · JavaService
  • ContainerRuntime · GenericProcess

REST API Reference

All endpoints are on the deployed backend URL. All accept/return JSON.

GET /api/status

Version, deployment time, current config.

POST /api/evaluate

Body: {"expression":"Prime[100]"} → {"result":"541"}

POST /api/alpha

Body: {"query":"mass of sun"} → {"result":"1.989×10^30 kg"}

GET /api/context

Returns {"processes":[...],"system":{...}}

GET/POST /api/config

Read or merge keys into $AppConfig without redeploying.
